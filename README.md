# AI Shopping Guide

面向消费者的购物任务，提供从需求到订单确认的一条龙智能导购服务

## 背景

消费者完成购物在信息繁杂的情况下具有五大障碍：不知道买什么、不知道自己需要什么、看不懂商品、不知道哪个好、不知道怎么去组合订单，利用 ai 降低消费者需要花费的认知成本。

## 需求

帮助用户把模糊的消费意图，整理成可执行的购物订单，而不是只给一份商品列表。

典型场景包括：

- 购物目的不明确：只知道使用场景和目的，不知道需要什么用品
- 需求不明确：知道自己需要商品，不确定自己的细化使用需求
- 看不懂商品：不知道商品的参数描述，
- 选不好商品：不知道哪个商品更加值得选购，更加契合当下情况


## 目标

通过对话理解用户的场景、需求和偏好，给出结构化的购物建议：买什么、为什么买、怎么选。

本仓库用于该智能导购能力的研发。
